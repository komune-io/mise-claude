the problem

Agent tooling drifts. chord keeps it in tune.

MCP servers, skills, plugins and CLIs live in a dozen configs, scattered across machines. They fall out of sync, break onboarding, and can't be reproduced. chord makes the whole set declarative: one file describes the environment, one command reproduces it — everywhere.

◔

One file, everything

MCP servers, skills, plugins and CLI tools declared together in chord.toml.

◑

Reproducible

chord install brings the same environment up on every machine — no drift.

◕

mise-native

Ships as a mise backend plugin; fills in missing tools transparently on shell entry.

●

Audit & clean

chord inspect surfaces drift; chord clean reverses an install cleanly.

one declaration

Four sections. One environment.

# chord.toml
[mcp.github]
command = "gh-mcp"

[skills]
brainstorming = "latest"
systematic-debugging = "latest"

[plugins]
figma = "1.4"

[cli]
ripgrep = "14.1"
MCP servers
Model-context servers your agent talks to.
Skills
Reusable agent skills, pinned to a version.
Plugins
Editor / tool plugins the environment needs.
CLI tools
Binaries resolved and installed for you.
get started

Install chord

Via cargo recommended

# install the binary
cargo install rytmyk-chord
# declare tools in chord.toml, then
chord install
chord inspect

Via mise plugin

# optional — bootstraps chord on shell entry
mise plugin install chord \
  https://github.com/rytmyk-ai/chord
chord install
